PHP環境マニュアル

本環境で PHP を使ってスクリプトを実行するときの手順と注意点をまとめています。

実行方法

PHP スクリプトファイルを php コマンドで直接実行します。

php sample.php

実行例

hello.php を作成して実行します。

<?php
echo "Hello, World!\n";

php hello.php

注意点

  • Composer などの外部パッケージ管理は想定していません：本環境は最小構成の固定パッケージで動作するため、実行中に外部からパッケージを追加導入する前提では書かないでください。
  • CLI 実行が基本です：Web サーバーを経由せず、コマンドラインから php コマンドでスクリプトを実行する形になります。
  • sqlite3 コマンドも利用できます：PHP の SQLite3 機能に加えて sqlite も導入しているため、ターミナルから直接データベースファイルを確認できます。

応用・補足

複数ファイルでの分割

関数やクラスを別ファイル（例：calc.php）に分けた場合は、メイン側から require または include して読み込みます。

<?php
require __DIR__ . "/calc.php";

SQLite との連携

SQLite3 クラスを使うと、ワークスペース内のデータベースファイルに対してテーブル作成やクエリ実行を試せます。

<?php
$db = new SQLite3("app.db");
$db->exec("CREATE TABLE IF NOT EXISTS items (id INTEGER PRIMARY KEY, name TEXT)");
$db->close();
