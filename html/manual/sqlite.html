SQLite環境マニュアル

本環境で SQLite3 を使って SQL を実行するときの手順と注意点をまとめています。

実行方法

データベースファイルを指定して sqlite3 を起動するか、SQL ファイルを読み込ませて実行します。

sqlite3 sample.db < query.sql

実行例

テーブル作成とデータ挿入・取得を sqlite3 で実行します。

CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name TEXT
);
INSERT INTO users (name) VALUES ('Alice'), ('Bob');
SELECT * FROM users;

sqlite3 app.db < init.sql

注意点

  • 対話モードを抜けるときは .quit を使います：sqlite3 を対話形式で起動した場合は、.quit を入力して終了してください。

応用・補足

インメモリデータベースでの検証

ファイルを作らず一時的に試したい場合は :memory: を指定して実行できます。

sqlite3 :memory: < query.sql

出力形式の整形

ドットコマンドを使うと、ヘッダ表示や区切り表示を切り替えながら結果を確認しやすくなります。

.headers on
.mode column
SELECT * FROM users;
