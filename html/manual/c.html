C / C++環境マニュアル

本環境で C / C++ を書くときのコンパイル方法と注意点をまとめています。

実行方法

ソースファイルを gcc または g++ でコンパイルして実行します。

gcc -m32 -no-pie sample.c -o app
./app

実行例

hello.c（C++ の場合は hello.cpp と g++）を作成してコンパイル・実行します。

#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}

gcc -m32 -no-pie hello.c -o app
./app

注意点

  • gdb は使えません：gdb によるデバッグは本環境ではできません。変数の値や処理の流れは出力文などで確認してください。
  • -m32 -no-pie の扱い：C / C++ 単体なら省略できることもありますが、アセンブリ連携や本環境の基準に合わせる場合は gcc -m32 -no-pie / g++ -m32 -no-pie を指定してください。

応用・補足

C++ でのビルドと複数ファイル

C++ ソースは g++ -m32 -no-pie でコンパイルし、複数ファイルに分ける場合はまとめて指定します。

g++ -m32 -no-pie main.cpp calc.cpp -o app
./app
