NASM環境マニュアル

本環境で NASM を使ってアセンブリを書くときのコンパイル方法と注意点をまとめています。

実行方法

アセンブリファイルを nasm でオブジェクト化し、gcc でリンクして実行します。

nasm -f elf32 sample.asm -o sample.o
gcc -m32 -no-pie sample.o -o app
./app

実行例

hello.asm を作成してビルド・実行します。

global main
extern printf

section .rodata
msg db "Hello, World!", 10, 0

section .text
main:
    push msg
    call printf
    add esp, 4
    xor eax, eax
    ret

nasm -f elf32 hello.asm -o hello.o
gcc -m32 -no-pie hello.o -o app
./app

注意点

  • ld だけでのリンクはできません：ld 単体での実行ファイル作成は本環境では無理です。gcc -m32 -no-pie でリンクしてください。
  • gdb は使えません：gdb によるデバッグは本環境ではできません。戻り値や計算結果は printf などで出力して確認してください。
  • main 定義とおまじないが必要：gcc でリンクして実行するには、global main で入口を用意し、引数や戻り値を整えて ret で戻る形にする必要があります。

応用・補足

Hello World のおまじないの意味

  • global main / extern printf：gcc から呼ばれる開始地点（main）を公開し、外部の printf を使う宣言です。
  • add esp, 4：push msg で積んだ引数（4バイト）をスタックから片付ける処理です。
  • xor eax, eax / ret：戻り値を 0 にして main を終わらせ、呼び出し元へ戻る処理です。

機械語バイト列（db）の記述

.asm ファイルの中に db 0x... と書くことで、機械語のバイト列を直接試すこともできます。

global mc_add1

section .text
mc_add1:
    db 0x8b, 0x44, 0x24, 0x04
    db 0x83, 0xc0, 0x01
    db 0xc3

命令名で書いたコードと並べて動かすと、命令とバイト列の対応を確認できます。
