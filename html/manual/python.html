Python環境マニュアル

本環境で Python を使ってプログラムを書くときの実行方法と注意点をまとめています。

実行方法

Python スクリプトファイルを python3 コマンドで直接実行します。

python3 sample.py

実行例

hello.py を作成して実行します。

print("Hello, World!")

python3 hello.py

注意点

  • pip は使えません：インターネット接続がない環境のため、外部パッケージのインストール（pip install など）はできません。標準ライブラリおよびあらかじめ導入されているパッケージのみで記述してください。
  • venv やバージョン切り替えには非対応です：Alpine のリポジトリに入っている python3 のみが用意されており、仮想環境の作成や複数バージョンの切り替えはできません。
  • パッケージは固定です：あらかじめ python3、py3-numpy、py3-pillow、sqlite が導入されています。

応用・補足

複数ファイルでの分割

処理を別ファイル（例：calc.py）に分けた場合は、メイン側から import して利用します。

python3 main.py

コマンドライン引数と標準入力

sys.argv や input() を使うと、実行時の引数や標準入力を受け取って動作を確認できます。
