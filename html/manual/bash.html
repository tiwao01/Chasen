sh / Bash環境マニュアル

本環境で sh / Bash や Unix コマンドを使って操作・スクリプト実行するときの手順と注意点をまとめています。

実行方法

シェルスクリプトファイルを sh または bash コマンドに渡すか、直接 Unix コマンドを入力して実行します。

bash sample.sh

実行例

hello.sh を作成して bash（または sh）で実行します。

#!/usr/bin/env bash
set -euo pipefail

echo "Hello, World!"
pwd
ls -la

bash hello.sh

注意点

  • sh と bash の両方を利用できます：標準の sh に加えて bash も導入されているため、目的に応じて使い分けてください。
  • 追加パッケージの取得には非対応です：オフライン・最小構成の環境のため、実行中に外部リポジトリからパッケージを追加取得する前提では書かないでください。
  • ファイル操作の影響に注意してください：rm や上書きリダイレクトなどのコマンドは作業ディレクトリ内のファイルに直接反映されるため、対象パスを確認してから実行してください。

応用・補足

パイプとフィルタコマンドの組み合わせ

テキスト処理や検索の練習では、標準出力をパイプ（|）でつないでコマンドを組み合わせると挙動を確認しやすくなります。

ls -la | grep ".sh"

変数・ループ・条件分岐の検証

配列やブレース展開、for / if などの書き方を短いスクリプトやワンライナーで試せます。

for name in alpha beta gamma; do
    echo "item: $name"
done
