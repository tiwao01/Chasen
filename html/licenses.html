言語別環境

C / C++ 環境（Alpine build-base）

ライセンス: GPL-3.0 / GPL-2.0 / MIT / BSD / その他各種OSSライセンス（パッケージごとに異なります）

C / C++ のコンパイル・ビルド環境として Alpine Linux の build-base パッケージ群（GCC, G++, GNU Binutils, GNU Make, musl-dev, fortify-headers 等）を使用しています。各パッケージの正確なバージョンとライセンスは、イメージ内のパッケージ管理情報（apk info）またはビルド時のログから確認できます。

GPL 等のライセンスに基づく各ソフトウェアのソースコードおよびパッケージ定義（aports）は、Alpine Linux Packages および Alpine aports リポジトリ から参照・入手できます。
