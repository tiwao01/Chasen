IDEヘルプ

言語環境によらない、CHASEN IDEの基本的な画面構成と操作方法のガイドです。

1. 画面構成

CHASEN IDEの画面は、大きく4つのエリアに分かれています。

  • トップバー（画面上部）：ホームへの移動、現在の実行環境の確認、プロジェクト全体のZIPダウンロード・アップロード、ヘルプの表示を行います。
  • ファイルエクスプローラー（画面左側）：プロジェクト内のファイルやフォルダーの一覧表示、新規作成、管理を行います。
  • コードエディタ（画面中央）：開いたファイルのソースコードを編集します。タブによる複数ファイルの切り替えや、画面分割（ドッキングレイアウト）が可能です。
  • ターミナル（画面下部）：仮想Linux環境（Alpine Linuxベース）のシェル操作、コンパイル、プログラムの実行、コマンド入力を行います。

2. トップバーの操作

CHASEN（ホームボタン）

トップページへ戻ります。作業中のデータはブラウザ内の仮想環境に保持されますが、ページ遷移前に必要に応じてダウンロード保存を行うことを推奨します。

環境バッジ

現在起動しているプログラミング言語や実行環境のステータス（起動中は Loading...、準備完了後に環境動作中）が表示されます。

Download（プロジェクトのエクスポート）

現在の作業ディレクトリ/workspace内のファイル一式をZIPアーカイブとしてローカルPCにダウンロードします。作業内容のバックアップや提出用データの作成に使用します。

※Download実行時、編集中のすべてのファイルは自動的に保存されます。

Upload（プロジェクトのインポート）

ローカルPCにあるZIPファイルを選択し、仮想環境内の作業ディレクトリに展開・復元します。既存のプロジェクトの続きから作業する場合に使用します。

※Uploadすると、作業ディレクトリ/workspace内のすべてのファイルを取り除いて、アップロードされる環境で上書きされます。

3. ファイルエクスプローラーの操作

左側のサイドバー（Files）からファイル操作を行います。

  • ファイルを開く：ツリー内のファイル名をクリックすると、中央のエディタタブに開きます。
  • 新しいファイル：ヘッダーのファイル追加アイコンをクリックし、ファイル名を入力して作成します。
  • 新しいフォルダー：ヘッダーのフォルダー追加アイコンをクリックし、フォルダー名を入力して作成します。
  • 最新の情報に更新：更新アイコンをクリックすると、ターミナル上のコマンド（mkdir や touch、ビルド生成物など）で変更されたファイル状態をツリーに再読み込みします。
  • フォルダーを折りたたむ：折りたたみアイコンをクリックすると、展開されているすべてのフォルダーを一括で閉じます。
  • コンテキストメニュー・名前変更・削除：ファイルやフォルダーの右クリックメニュー、またはツリー上の操作から名前の変更（Rename）や削除（Delete）が行えます。

4. コードエディタの使い方

エディタには Monaco Editor を採用しており、VS Code に近い操作感でコーディングできます。

  • タブ切り替え・閉じる：上部のタブバーから編集するファイルを切り替えます。タブの「×」ボタンでファイルを閉じます。
  • 保存：編集内容は仮想ファイルシステムへ反映されます。保存する場合は Ctrl + S（Macは Cmd + S）を使用します。
  • 主なショートカットキー：
    • Ctrl + F / Cmd + F：ファイル内検索
    • Ctrl + H / Cmd + Option + F：置換
    • Ctrl + / / Cmd + /：行コメントの切り替え
    • Ctrl + Z / Cmd + Z：元に戻す
    • F1 または Ctrl + Shift + P：コマンドパレットの表示

5. ターミナルとプログラムの実行

画面下部のターミナルでは、ブラウザ上で動作する仮想Linux環境（x86互換環境 / Alpine Linuxベース）のシェルを直接操作できます。

  • コマンド入力と実行：通常のLinuxシェルと同様に、各種コマンドの実行やスクリプトの起動が可能です。
  • コンパイルと実行（例：C / C++ 環境）： 
    gcc main.c -o main
./main
  • コピー＆ペースト：ターミナル内のテキストを選択してコピー、または右クリックや Ctrl + Shift + V（環境により Ctrl + V / Cmd + V）で貼り付けができます。
  • 実行の中断：無限ループなどでプログラムが停止しない場合は、ターミナル上をクリックしてフォーカスを当てた状態で Ctrl + C を押すと強制終了できます。

6. 注意事項・トラブルシューティング

  • 初回起動時の読み込み：初回アクセス時やキャッシュクリア後は、仮想環境のディスクイメージ（rootfs）のダウンロードと展開に数秒〜数十秒かかる場合があります。トップバーのステータスが変わるまでお待ちください。
  • データの永続化について：仮想環境内のファイルはブラウザのストレージに保持されますが、ブラウザのサイトデータ削除やシークレットウィンドウの終了によって消去されます。重要なコードはこまめに右上の Download ボタンからZIPで保存してください。
  • ファイルツリーに反映されない場合：ターミナル上で作成したファイルが表示されない場合は、ファイルエクスプローラー右上の「最新の情報に更新」アイコンを押してください。
